# AFTERHOURS

Browser horror game: singleplayer + multiplayer architecture.

- Enemy patrol/chase/search AI
- Sprint, stamina, sanity
- Keys, exit objective
- Random horror events
- Room-code multiplayer
- Supabase Realtime Broadcast + Presence
- Supabase database schema

Put your Supabase URL and publishable key in `config.js`. Run `supabase/schema.sql` in SQL Editor. Never expose a service_role key.

Controls: WASD, Shift, E, R
